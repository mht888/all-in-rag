# 医学RAG项目依赖 —— cook-rag-1 已验证环境全量冻结清单
#
# 重要: 本清单是实测可运行环境的完整克隆（含全部传递依赖）。
#       该版本组合为逐包升级形成的历史状态，包间存在 metadata 声明冲突
#      （如 langchain-text-splitters 0.3.8 声明 langchain-core<1.0，与已装
#        langchain-core 1.6.12 冲突），正常依赖解析必然报 ResolutionImpossible，
#       因此必须使用 --no-deps 安装。
#
# 安装步骤（medical 为空环境时的完整流程，共 4 步）:
#   conda create -n medical python=3.12 -y
#   conda activate medical
#   1. pip install --no-deps -r requirements.txt
#   2. pip install "unstructured[pdf]==0.18.11"      # 正常解析补齐 PDF extras
#      （pi_heif / pdf2image / unstructured-inference 等为 partition_pdf
#        顶层 import 必需，主清单未含，cook-rag-1 从未走过 partition_pdf）
#   3. pip install pdfminer.six==20250506             # 锁定 unstructured 0.18.11
#      配套版本（新版会移除 psexceptions 等模块，老版缺少 open_filename，
#      均导致 ImportError——unstructured unpinned 声明必须手动锁此版本）
#   4. 安装 CUDA 版 torch + torchvision（成对安装，版本号与主清单一致，见下方注意）
#
# 注意:
#   - torch 必须用 CUDA 版，且必须与 torchvision 成对装同一种构建，
#     版本号与主清单保持一致（torch 2.14.1 / torchvision 0.29.1）。
#     历史教训：只把 torch 换成 CUDA 版、而 torchvision 仍是第 2 步带进来的
#     CPU 版时，Windows 下二者 DLL 冲突，加载 bge-m3 时进程退出
#     exit code 3221225477（0xC0000005 访问违例）。
#     正确安装（已实测，驱动 CUDA 13.x / RTX 40 系可用）:
#         从 https://download.pytorch.org/whl/cu130/ 下载成对的 wheel 后
#         pip install --no-deps torch-2.14.1+cu130-cp312-cp312-win_amd64.whl \
#                        torchvision-0.29.1+cu130-cp312-cp312-win_amd64.whl
#     （pip 直连 download-r2.pytorch.org 网络不稳时，可用 curl 下 wheel 再本地装）
#   - 不要安装 torchaudio（会导致加载错误）
#   - 本清单包含 cook-rag-1 的全部包（含 streamlit 等本项目用不到的包，
#     保留是为零偏差克隆，避免误删间接依赖）
#   - 升级任何包前慎重: 版本组合是整体验证的，动一个可能全崩
